# VLXR

**PC VR streaming, pushed to the limit.**

VLXR is a closed-source runtime and streamer for Meta Quest 3 on Windows,
built to drive every refresh rate the headset supports — up to 207 Hz —
with precise frame pacing and live control from the PC and inside the
headset.

**Status: in development. Coming soon.**

This repository hosts the public project page and brand assets only.
The application itself is closed source and is not distributed here.
